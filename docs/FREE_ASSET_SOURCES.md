## How to Use These Assets

### After Downloading:

1. **For Character Sprites:**
   - Download the pack
   - Extract the ZIP
   - Find the character spritesheet (16x16 or 32x32)
   - Copy to `/game/assets/sprites/player/`
   - Rename to `player_spritesheet.png`
   - Reimport in Godot

2. **For Tilesets:**
   - Download the tileset
   - Extract ZIP
   - Find the tileset PNG
   - Copy to `/game/assets/tilesets/`
   - Rename to `main_tileset.png`
   - Reimport in Godot

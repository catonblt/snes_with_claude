## Step 1: Install Godot (5 minutes)

1. Go to https://godotengine.org/download
2. Download **Godot 4.2** (Standard version)
3. Extract the ZIP
4. Run Godot (no installation needed)

**Cost: FREE**

---

## Step 2: Import the Project (1 minute)

1. Launch Godot
2. Click **"Import"**
3. Click **"Browse"**
4. Navigate to this folder: `/game/`
5. Select `project.godot`
6. Click **"Import & Edit"**
7. Wait ~10 seconds for initial import

## Step 3: Play! (Immediately)

1. Press **F5** or click the **Play ▶** button
2. Game launches instantly!

## Troubleshooting

### "Godot won't open the project"
- Make sure you have Godot 4.2+ (not 3.x)
- Try "Scan" instead of "Import"

### "I see error messages"
- Click "Ignore" - usually just asset import warnings
- If game doesn't run, check Output panel (F4)

### "Graphics look blurry"
- Project settings already configured for pixel-perfect
- If still blurry, check Project → Project Settings → Rendering → Textures
- Default Texture Filter should be "Nearest" (0)

### "Player won't move"
- Check that player.gd script is attached
- Look at Output panel (F4) for errors
- Try restarting Godot
